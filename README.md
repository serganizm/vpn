# vpn

VPN Manager — OpenVPN control plane for a two-server GRE pair.

## App `0.1.0`

See [`app/README.md`](app/README.md).

```bash
cd app
go build -o bin/vpn-manager ./cmd/vpn-manager
./bin/vpn-manager
```

Then open http://127.0.0.1:8787/
